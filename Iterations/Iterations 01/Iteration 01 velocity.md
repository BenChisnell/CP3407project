v1 = velocity in iteration-1

E1 / v1 = A1, or A1 * v1 = E1

A1 = E1 / v1 = E2 / v2, then v2 = E2/E1 * v1,

for example, E2 = 60, then v2 = (60/70) * 0.7 = 0.6
