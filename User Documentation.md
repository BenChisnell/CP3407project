
## Home Page

### Navigation
The top right corner of the page features the navigation bar, in which users can access the Home, 
About Us, Contact Us, Account, My Orders and Log In pages. 

### Create an account
Users can create an account by clicking the login button in the header. On this page, new users can create an account, whil existing users can log in with their account details. To create an account, users must provide their first name, last name, email address, phone number, password and confirmation of the password. To log in, users only need to enter their email address and password.

### Search
Users can access the search functionality by clicking on the green "feed me now" button
or by scrolling down on the home page. From here, users can input their desired food into the
search bar and it will search the database and return locations with the input in its name or menu.
Users can also click on one of the three drop down menus to the right of the search bar to apply filters
based on preferences such as price, distance and dietary restrictions. Once the search has been inputted
restaurants will be displayed below based on the parameters given.
