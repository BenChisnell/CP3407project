# User story title: Filter restaurants by cuisine

## Priority: 40
Priority is a 40 because applying promo codes adds value by helping users save money and can encourage conversions, but it is not essential to the core functionality of browsing, ordering, and completing a purchase.

## Assumptions:
* Users have access to valid promo codes (e.g., from promotions, emails, or partnerships) and expect to use them during checkout.
* The system can validate promo codes in real time, including expiry dates, usage limits, and eligibility conditions.
* Discounts are correctly applied to the order total without causing calculation errors or inconsistencies.

## Description: 
As a user of the app, Michael a Male aged 42 wants to apply promo codes during checkout so that he can reduce the total cost of my order and take advantage of available discounts or special offers.
