
# User story title: Select pickup or delivery

## Priority: 10
Priority is a 10 because allowing users to choose between pickup and delivery is a core ordering function, directly affecting how an order is fulfilled. Without this option, users cannot tailor the service to their needs, making it essential to the app’s functionality.

## Assumptions:
* Restaurants support either pickup, delivery, or both, and this information is accurately reflected in the app.

## Description: 
As a user of the app, James a male aged 38 wants to select between pickup or delivery so that he can choose the most convenient option based on his situation, time, and location.
